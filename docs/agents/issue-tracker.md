# Issue tracker

- Use GitHub Issues in `qu1r0ra/jute-related-image-evaluation` as the repository-native tracker. Pass `--repo qu1r0ra/jute-related-image-evaluation` explicitly to issue commands.

- Find the live index by its label: the one open `wayfinder:map` issue. It is an execution parent whose children are tickets, so every open issue is its child and its execution map gives the order. Use native child issues and blocker relationships.
- If no canonical repository-native map/spec exists, wait for approved tracker setup or migration before creating or mutating implementation issues. Configuring this destination does not perform or authorize migration. Keep one canonical queue; do not create a parallel local or external queue.

- Claim an issue before work. Record resolution in an issue comment and close only after acceptance. Keep the index's title-linked list and execution map in step with every child and blocker change.
- Validate draft shape, routing, and relationships before writing; read back exact live state after each successful write. Delete successful temporary drafts.

- Pull requests are not the request surface.
